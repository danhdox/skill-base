# Security Policy

## Supported Versions

The repository follows a rolling support model on the default branch.

| Version | Supported |
|---|---|
| `main` | Yes |
| Older tags | Best effort |

## Reporting a Vulnerability

Please do not open a public issue for potential vulnerabilities.

1. Email the maintainers at `security@skill-base.dev` with details.
2. Include reproduction steps, affected files, and potential impact.
3. Provide suggested remediation if available.

We will acknowledge reports within 3 business days and provide status updates until resolution.

## Disclosure Process

- Confirm severity and scope.
- Prepare and validate a fix.
- Publish remediation notes in a release or changelog entry.
- Credit reporters when permission is granted.
